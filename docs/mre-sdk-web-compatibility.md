# MRE SDK Web Compatibility Analysis & Abstraction Mapping

This document provides a comprehensive analysis of every MediaTek MRE C SDK API header (`vm*.h`) used in **MREmu**, categorizes functions by platform subsystem, details their browser compatibility, and outlines the browser-compatible abstraction layer for WebAssembly deployment.

---

## 1. MRE SDK Header Overview

The emulator relies on the following MRE SDK headers:
- `vmsys.h` / `vmpromng.h`: System, process, and application lifecycle management.
- `vmgraph.h` / `vmgfxold.h`: Graphics primitives, layers, canvas drawing, and framebuffers.
- `vmmm.h` / `vmbitstream.h`: Audio playback (MIDI, WAV, MP3), audio resource streaming, and bitstream recording/playback.
- `vmio.h`: Filesystem operations, file handles, and directory searching.
- `vmtimer.h`: System timers and periodic callbacks.
- `vmsim.h`: SIM card info, IMEI/IMSI numbers, and network status.
- `vmchset.h`: Character encoding (UCS-2, UTF-8, GB2312) conversions.
- `vmstdlib.h`: Custom C standard library functions (sprintf, sscanf, malloc wrappers).
- `vmsensor.h`: Device sensors (accelerometer).
- `vmgettag.h` / `vmcert.h`: VXP metadata tags and digital certificate verification.
- `vmsock.h`: Network sockets.
- `vmres.h` / `vm4res.h`: Embedded application resources.

## 2. API Categorization & Browser Compatibility Matrix

### 2.1 CPU & Runtime (`vmsys.h`, `vmpromng.h`, `vmcert.h`, `vmgettag.h`)
- **APIs Used:**
  - `vm_pmng_get_current_handle()`
  - `vm_get_sym_entry()`
  - `vm_get_exec_path()`
  - `vm_get_system_driver()`
  - `vm_reg_sysevt_callback()`
  - `vm_reg_msg_proc()`
  - `vm_exit_app()`
- **Browser Compatibility:**
  - **100% Compatible via WASM Memory / Emscripten:** App lifecycle callbacks are registered in C++ (`Bridge.cpp`, `AppManager.cpp`) and dispatched via WASM function tables.
  - Native Windows DLL execution (`DLLApp.cpp`) is excluded on WebAssembly.

### 2.2 Memory (`vmstdlib.h`, `vmsys.h`)
- **APIs Used:**
  - `vm_malloc()`, `vm_calloc()`, `vm_realloc()`, `vm_free()`
  - `vm_get_user_heap()`
- **Browser Compatibility:**
  - **100% Compatible:** Allocated inside linear emulated RAM (`Memory::shared_malloc`) allocated in WASM linear heap (`WebAssembly.Memory`).

### 2.3 Graphics & Rendering (`vmgraph.h`, `vmgfxold.h`)
- **APIs Used:**
  - Layer Management: `vm_graphic_create_layer()`, `vm_graphic_delete_layer()`, `vm_graphic_active_layer()`, `vm_graphic_get_layer_buffer()`
  - Drawing Primitives: `vm_graphic_line()`, `vm_graphic_rect()`, `vm_graphic_fill_rect()`, `vm_graphic_ellipse()`
  - Canvas & Blitting: `vm_graphic_blt()`, `vm_graphic_blt_ex()`, `vm_graphic_canvas_to_layer()`
  - Framebuffer & Text Output: `vm_graphic_textout()`, `vm_graphic_get_character_height()`
- **Browser Compatibility & Web Abstraction:**
  - **Compatible via WebGL / SDL2 Canvas:** Framebuffers maintained in RGB565 / ARGB8888 are rendered directly to HTML5 Canvas via SDL2 (`-sUSE_SDL=2`) or WebGL pixel upload.

### 2.4 Audio Subsystem (`vmmm.h`, `vmbitstream.h`)
- **APIs Used:**
  - MIDI Playback: `vm_midi_play()`, `vm_midi_pause()`, `vm_midi_stop()`, `vm_midi_set_volume()`
  - Audio Stream: `vm_audio_play_open()`, `vm_audio_play_start()`
  - Bitstream: `vm_bitstream_open()`, `vm_bitstream_play()`
- **Browser Compatibility & Web Abstraction:**
  - **Compatible via Web Audio API / SDL2 Audio:** Raw 16-bit PCM generated by `libADLMIDI` is queued to `SDL_OpenAudioDevice` or processed in an `AudioWorkletNode`.
  - Autoplay restrictions: Web Audio context resumed upon first user click/touch event on the HTML canvas.

### 2.5 Filesystem (`vmio.h`)
- **APIs Used:**
  - File I/O: `vm_file_open()`, `vm_file_read()`, `vm_file_write()`, `vm_file_seek()`, `vm_file_close()`, `vm_file_tell()`
  - Directory & Search: `vm_find_first()`, `vm_find_next()`, `vm_find_close()`
  - File Management: `vm_file_delete()`, `vm_file_rename()`, `vm_file_mkdir()`
- **Browser Compatibility & Web Abstraction:**
  - **Compatible via Emscripten Virtual Filesystem:** Maps MRE drives (`C:\`, `E:\`, `D:\`) to MEMFS / IDBFS persistent storage in browser IndexedDB.

### 2.6 Timing & Callbacks (`vmtimer.h`, `vmsys.h`)
- **APIs Used:**
  - `vm_create_timer()`, `vm_delete_timer()`
  - `vm_create_timer_ex()`, `vm_delete_timer_ex()`
  - `vm_get_time()`, `vm_get_tick_count()`
- **Browser Compatibility:**
  - **Compatible via JS requestAnimationFrame / emscripten_set_main_loop:** Timers updated during per-frame tick updates (`AppManager::update(delta_ms)`).

### 2.7 Input Handling (`vmio.h`, `vmsys.h`)
- **APIs Used:**
  - Key events: `VM_KEY_EVENT_KEY_DOWN`, `VM_KEY_EVENT_KEY_UP`
  - Touch pen events: `VM_PEN_EVENT_TAP`, `VM_PEN_EVENT_MOVE`, `VM_PEN_EVENT_RELEASE`
- **Browser Compatibility:**
  - **Compatible via HTML5 Event Listeners:** DOM keydown/keyup and touch/mouse events mapped to MRE keycodes and pen coordinates.

### 2.8 Networking & Sockets (`vmsock.h`)
- **APIs Used:**
  - `vm_tcp_connect()`, `vm_tcp_close()`, `vm_tcp_read()`, `vm_tcp_write()`
- **Browser Compatibility:**
  - **Requires WebSocket Proxy:** Direct raw TCP BSD sockets are blocked in Web Browsers. Sockets mapped to WebSockets (`-sWEBSOCKETS=1`) routed through a WebSocket-to-TCP proxy server.

## 3. Unsupported / Currently Restricted MRE SDK APIs

The following APIs cannot be natively supported inside standard web browser security sandboxes and will return default safe stub values:
1. **Device Hardware Sensors (`vmsensor.h`):** Physical accelerometer sensor APIs return `0` unless bound to HTML5 `DeviceOrientation` events.
2. **Device Vibration (`jni/Vibration.cpp`):** Mapped to HTML5 `navigator.vibrate()` where supported by browser permissions.
3. **SIM & Telephony Info (`vmsim.h`):** `vm_sim_get_imei()`, `vm_sim_get_imsi()` return static mock identifier strings.
4. **Direct Raw Socket Listening (`vmsock.h`):** Server socket listening (`bind`/`listen`) is unsupported due to browser sandbox restrictions.
